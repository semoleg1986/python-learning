# 🔹 День 5 — Git Flow, теги, revert и reset

## 🧠 Теория

### Git Flow: организация веток
- main — стабильная версия
- develop — активная разработка
- feature/* — временные ветки для задач

### Работа с тегами:

- git tag — создание, просмотр и удаление тегов
- git revert — безопасное откатывание конкретного коммита
- git reset — жёсткий откат изменений (меняет историю)
