# 🔹 День 2 — Работа с ветками и удалённым репозиторием

## 🧠 Теория

### 📌 Ветки в Git
Ветка (branch) — это независимая линия разработки, позволяющая вносить изменения, не затрагивая основную ветку (`main`).

### Основные команды:   
| Команда                            | Назначение                                     |
|------------------------------------|------------------------------------------------|
| `git branch`                       | Показать все ветки                             |
| `git branch [branch-name]`         | Создать новую ветку                            |
| `git checkout [branch-name]`       | Переключиться на ветку                         |
| `git checkout -b dev "`            | Создать и сразу перейти                        |
| `git merge [branch-name]`          | Сливаем изменения из branch-name в main        |
| `git remote add origin <URL>`      | Подключить удалённый репозиторий               |
| `git remote -v `                   | Проверить подключение                          |
| `git push -u origin main`          | Отправить основную ветку в GitHub (первый раз) |
| `git push -u origin [branch-name]` | Отправить конкретную ветку                     |
