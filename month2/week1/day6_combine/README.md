# 🔹 День 6 — Комбинированные задачи: Фильтрация и поиск

---

В этом дне реализована поддержка комбинированных запросов, позволяющих выполнять поиск, фильтрацию и комбинирование параметров при работе с коллекциями данных.
Основная цель — научиться использовать Query-параметры и правильно организовать бизнес-логику на уровне сервиса и репозитория.
