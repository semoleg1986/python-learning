# 🔹 День 1 — Основы Git

## 🧠 Теория

**Git** — это распределённая система контроля версий.  
Она позволяет отслеживать изменения в коде, откатываться к предыдущим версиям и работать в команде над одним проектом.

### Основные команды

| Команда                     | Назначение                                       |
|-----------------------------|--------------------------------------------------|
| `git init`                  | Инициализирует новый репозиторий в текущей папке |
| `git status`                | Показывает изменённые и неотслеживаемые файлы    |
| `git add <файл>`            | Добавляет файл в staging area                    |
| `git commit -m "сообщение"` | Создаёт коммит (снимок состояния)                |
| `git log`                   | Показывает историю коммитов                      |
| `git diff`                  | Показывает различия между версиями               |
| `git checkout <commit>`     | Переключение на конкретную версию                |
